# AI-Powered Intelligent Document Analysis System

An AI-based PDF document analysis system developed using Python and Streamlit for context-based question answering and automated PDF highlighting.

---

## Features
- PDF Question Answering
- Semantic Retrieval
- Automated Highlighting
- Streamlit-Based Interface
- Offline Processing

---

## Technologies Used
- Python
- Streamlit
- FAISS
- PyMuPDF
- Sentence Transformers
- Transformers

---

## Project Structure

```bash
Intelligent_Document_Analysis/
│
├── app.py

```

---

## Installation

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## Run the Project

```bash
py -3.11 -m streamlit run app.py
```
